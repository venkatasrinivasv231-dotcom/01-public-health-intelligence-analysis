# UK Public Health Intelligence Analysis

## Overview

This project demonstrates an end-to-end public health data analytics
workflow using publicly available UK health data.

## Objectives

- Clean and validate public health data
- Perform SQL analysis
- Conduct exploratory data analysis using Python
- Identify trends and regional variation
- Develop an interactive Power BI dashboard
- Communicate actionable insights

## Technologies

- Python
- Pandas
- SQL
- Power BI
- DAX
- Power Query
- GitHub

## Project Workflow

Data Collection
→ Data Cleaning
→ Data Validation
→ SQL Analysis
→ Statistical Analysis
→ Power BI Dashboard
→ Insights

## Skills Demonstrated

Data Analysis • SQL • Python • Data Quality •
Power BI • Data Visualisation • Public Health Analytics
